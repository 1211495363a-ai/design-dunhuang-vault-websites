# 燕云十六声·河西环境审美 Skill

## 0. 核心定义

本 Skill 的目标，是把《燕云十六声》河西区域中的**环境美术语言**转译为一套可复现的设计系统，而不是复刻游戏截图，也不是制作游戏宣传视觉。

固定识别式：

> **河西空间骨架 × 边塞遗迹 × 风蚀材质 × 绿洲水系 × 石窟/壁画装饰语言 × 克制的矿物色。**

### 硬性边界

任何使用本 Skill 的成品都必须遵守：

- 不出现人物主角。
- 不出现侠客、NPC、骑马者、驼队人物、角色剪影。
- 不以武侠剧情、战斗、任务或角色关系组织画面。
- 不出现网游 UI、小地图、血条、任务框、技能图标、装备框、游戏宣传页式构图。
- 不把“燕云十六声”理解为角色或 IP 宣传模板；只提取其河西区域的场景与设计审美元素。
- 若需要表现“行旅”，只能使用道路、车辙、驿站、旗幡残片、绳索、路标、门洞、磨损等**环境痕迹**。

# 1. 视觉识别核心

## 1.1 六个母题

每个主要成品至少使用其中 4 项：

1. **大尺度荒野**：戈壁、荒丘、雅丹、风蚀岩壁、远山、干旱河谷。画面必须保留辽阔天空或连续远景。
2. **边塞建筑与遗迹**：夯土城墙、残垣、烽燧、关隘、堡寨、驿站、塔楼、城门。形体厚重、低矮、耐风沙，带时间侵蚀。
3. **绿洲与水系**：河道、浅滩、湿地、水岸、胡杨、绿洲聚落。绿洲是荒凉空间中的小比例生机，不做江南园林。
4. **石窟与壁面文明痕迹**：崖壁洞窟、龛室、石刻、残彩、灰泥底、褪色壁面。强调历史留痕，不把宗教人物图像当主视觉。
5. **丝路装饰语言**：云气、忍冬、莲瓣、连珠、几何边饰、卷草、藻井式分区逻辑。纹样是辅助结构，不是主角。
6. **风沙与时间感**：粉化、剥落、干裂、磨损、颗粒、沙尘、旧纸、旧木、旧织物。

## 1.2 固定气质

**苍茫、古朴、辽阔、风蚀、安静、厚重、诗性、文明遗痕、荒凉中的生机。**

避免主导：**仙气、宫廷华丽、江南婉约、甜美、赛博、霓虹、国潮金黑、二游宣传、角色卡、影视海报感。**

# 2. 场景优先级

默认视觉权重：

- 35% 地貌与空间
- 25% 建筑与遗迹
- 15% 绿洲/水系/自然植被
- 15% 材质与历史痕迹
- 10% 纹样与装饰

第一眼应先读到“河西环境”，第二眼才看到纹样和文化细节。若第一眼只看到敦煌纹样、飞天、莲花或国风装饰，则判定偏移。

# 3. 地貌语言

优先使用：大漠戈壁、雅丹与风蚀孤峰、荒丘与裸岩坡地、高原河谷、干旱水系、绿洲边缘、沙砾地表、长距离地平线。

空间规则：

- 至少保留一处明显远景。
- 中景承担建筑、遗址或水系信息。
- 前景只做少量岩石、残墙、木构、布幡等框景。
- 不用人物作为尺度参照；改用门洞、塔楼、城墙、树木或道路宽度建立比例。

# 4. 建筑与遗迹语言

形体：厚墙、低层、方正或层叠体块、高点烽燧/塔楼、崖体与建筑嵌合、门洞与城墙缺口形成纵深。

材质：夯土、土砖、风化石、旧木、灰泥、壁画底层。

禁止：崭新影视城感、雕梁画栋式宫廷建筑、江南白墙黑瓦、大量金色屋顶、仙宫和浮空建筑。

# 5. 纹样系统

一级纹样：云气纹、忍冬/卷草、莲瓣结构、连珠边饰、几何连续纹、藻井式套层结构。

二级纹样：瑞兽轮廓、鹿纹、禽鸟纹、丝织式条带纹、菱格与放射纹。

规则：

- 页面级只设 1 个主纹样家族。
- 纹样只占视觉信息的约 10%。
- 背景隐纹保持弱视觉强度，避免完整铺满。
- 优先表现残损、掉色、断裂、粉化。
- 不使用飞天或宗教人物作为主画面。

# 6. 色彩系统

| Token | HEX | 用途 |
|---|---|---|
| hexi-parchment | #E6D4B1 | 主底、古纸、浅墙面 |
| desert-sand | #C7A36A | 沙地、暖中性色 |
| earth-ochre | #A87940 | 岩土、建筑 |
| weathered-umber | #6F5138 | 暗部、旧木、深墙体 |
| rust-red | #934B38 | 残彩、边饰、重点 |
| mineral-green | #567A6E | 壁画、绿洲、小面积点缀 |
| lapis-blue | #425D79 | 矿物蓝、极少量冷色 |
| ink-brown | #30261F | 文字、轮廓、最深部 |
| bone-white | #EFE4CC | 高光、浅卡片、留白 |

默认比例：50% 米白/沙金，25% 土黄/赭石/褐色，10% 锈红，6% 石绿，3% 青金蓝，6% 墨褐。

# 7. 材质系统

优先级：风沙颗粒、夯土干裂、风蚀岩层、壁画粉化与剥落、灰泥底、旧木干裂、古纸纤维、褪色织物。

数字设计建议：每个大区域使用 **1 个主材质 + 1 个细颗粒 + 1 个局部磨损层**。

# 8. 光影

默认使用低角度暖光、日出后或日落前、侧光/侧逆光、轻微沙尘与远景衰减。

远景低对比暖灰；中景沙金与赭石；前景深褐与少量暗红；高光骨白/金白；阴影暖灰褐。

禁用蓝紫霓虹、强 HDR、人物轮廓光、游戏宣传片式英雄光。

# 9. 构图模板

## A. 横向长卷
前景残墙/岩体 → 中景河谷/土城 → 远景雅丹/群山 → 大面积天空。

## B. 中央遗迹
用土城、石窟、烽燧或关隘作为唯一视觉中心；周围只允许低强度纹样辅助。

## C. 环境模块板
地貌、建筑、绿洲、纹样、色板、材质分区；不加入人物卡、装备卡、任务卡。

## D. 地图式信息构图
用路线、节点、遗址、河谷、城塞关系组织版面，但采用文化地图/编辑设计语言，不模仿游戏地图 UI。

# 10. 留白规则

- 天空、荒地、旧纸和墙面可承担大面积留白。
- 装饰不得填满四角。
- 纹样必须让位于空间和建筑。
- 页面文字区保持连续、安静的背景。

目标不是“装饰越多越河西”，而是让历史痕迹在空旷中出现。

# 11. 适配网页与平面设计

网页：首屏优先大场景或抽象地貌，不用人物英雄图；导航与按钮现代克制；纹样用于分隔、页脚、标题边饰和弱背景；不制作 RPG 面板。

海报/封面：只设一个场景核心；标题避免游戏 Logo 式字效；纹样只辅助边界与层次。

品牌/展陈：使用地貌轮廓、土城体块、纹样带、矿物色和材料肌理建立识别，不依赖角色形象。

# 12. 反偏移规则

- **偏成泛敦煌**：增加戈壁、雅丹、夯土城、烽燧、绿洲和河谷；减少飞天、莲花与完整壁画人物。
- **偏成网游/二游宣传**：删除全部角色、坐骑、武器、战斗信息、UI；让地貌与遗迹成为唯一主视觉。
- **偏成普通国潮**：降低金色和高饱和红；增加风蚀、粉化、夯土、远景与低饱和矿物色。
- **偏成旅游宣传**：减少明信片式蓝天与高饱和绿洲；增加历史侵蚀、残损、灰尘与克制留白。
- **偏成江南古风**：去掉亭台水榭、白墙黑瓦、花木繁盛；改用厚重土城、裸岩、干旱水系和疏落植被。

# 13. 标准执行流程

1. 明确用途。
2. 从六个母题中选至少 4 项。
3. 先定地貌与建筑空间，不先画纹样。
4. 从基础色板选主色，并限制石绿、青金用量。
5. 只选 1 个主纹样家族。
6. 加入 1–2 类风蚀/壁画/夯土材质。
7. 检查人物、游戏 UI、角色叙事是否为 0。
8. 缩略查看：第一眼是否仍然是河西环境。
9. 检查留白、空间纵深和场景结构。
10. 按反偏移规则复核。

# 14. 一句话调用指令

> 使用「燕云十六声·河西环境审美 Skill」：只提取河西区域中的地貌、边塞建筑、绿洲水系、石窟遗迹、色彩、材质与艺术纹样；禁止人物、角色、坐骑、战斗、剧情与网游 UI，以河西环境空间作为绝对主视觉。
