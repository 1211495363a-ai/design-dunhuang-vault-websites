## 视觉权重

- 地貌与空间：35%
- 建筑与遗迹：25%
- 绿洲/水系：15%
- 材质与历史痕迹：15%
- 纹样：10%

## 纹样强度

- 页面级主纹样家族：1 种
- 次级纹样：0–2 种
- 纹样总视觉占比：约 10%
- 背景纹样：弱、残损、不满铺

## 验收清单

- [ ] 无人物、无角色剪影
- [ ] 无坐骑、无战斗、无武器中心视觉
- [ ] 无游戏 UI
- [ ] 第一视觉中心是地貌/建筑/遗迹
- [ ] 至少一处明显远景
- [ ] 至少保留一块大面积留白
- [ ] 纹样没有压过场景
- [ ] 绿洲比例克制，不像江南园林
- [ ] 材质有风蚀与历史痕迹，但不过度做旧
- [ ] 配色以沙土、赭石、古纸为主体
- [ ] 石绿和青金只做点缀

## 推荐空间层次

近景：残墙 / 岩块 / 木构 / 旗幡残片

中景：土城 / 石窟 / 河谷 / 水岸 / 烽燧

远景：雅丹 / 荒丘 / 群山 / 天空

## 失败判断

出现以下任一情况应重新设计：

- 角色成为主视觉
- 看起来像游戏活动页
- 纹样比地貌更突出
- 大量飞天或宗教人物图像
- 金黑国潮成为主色逻辑
- 绿洲被画成江南园林
- 只剩“沙漠”，没有边塞与文明遗痕
