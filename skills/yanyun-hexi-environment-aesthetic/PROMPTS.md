# Prompt Templates

## 1. 通用环境视觉

以《燕云十六声》河西区域中的环境画面与设计语言为审美来源，仅提取河西地貌、边塞遗迹、绿洲水系、石窟、建筑、色彩、材质和纹样。禁止人物、角色、坐骑、武器、战斗、剧情、游戏界面或网游宣传构图。画面以大漠戈壁、风蚀雅丹、夯土城墙、烽燧、古驿道、石窟崖壁和绿洲为核心，使用低饱和沙金、土黄、赭石、丹赤、石绿与青金矿物色，结合风沙、岩层、壁画剥落、古纸和旧木肌理。强调环境尺度、历史痕迹、留白和自然光。

## 2. Web Design

使用河西环境审美体系设计网页。场景语言来自戈壁、雅丹、河谷、绿洲、边塞土城、烽燧、石窟和古道；装饰使用云气纹、莲瓣、忍冬、几何带饰和藻井结构拆解。主色为沙金、土黄、赭石和古纸米白，石绿与青金仅作小面积冷色点缀。网页布局应横向、宽阔、低密度、有留白，纹样只服务于分区和边框。不要人物，不要武侠角色，不要游戏 HUD，不要做成游戏活动页、国潮电商页或敦煌人物壁画页。

## 3. Poster / Editorial

设计一张无人环境海报，以河西的辽阔地貌与文明遗迹为视觉主体。可选择“雅丹 + 烽燧”“绿洲 + 石窟”“古道 + 土城”等组合。以自然风沙、夯土、岩石和壁画残彩建立表面质感；用几何带饰或云气纹建立版式边界。保持大面积天空、沙地或古纸色留白，不出现人物、英雄剪影、坐骑、武器、战斗或网游界面。

## 4. Moodboard / Skill Board

制作河西环境审美规范板，模块包括：地貌、建筑、石窟与壁画、纹样、色彩、材质、光影、构图。视觉样本全部使用无人场景或抽象纹样，不使用人物图像。重点表达河西空间、边塞遗迹、绿洲水系和风沙时间感，而不是把敦煌人物壁画作为主视觉。

## 5. Anti-drift

如果结果出现人物、骑马侠客、武器、战斗、游戏 UI、英雄式镜头或网游宣传感，全部删除。将视觉主体恢复为真实河西地貌、土城、烽燧、石窟、绿洲、古道与自然光。如果结果过于“泛敦煌”，减少飞天和人物壁画，增加戈壁、雅丹、边塞建筑与真实空间尺度。如果结果过于“国潮”，降低金黑、朱红和高饱和对比，恢复低饱和矿物色和风化材质。
