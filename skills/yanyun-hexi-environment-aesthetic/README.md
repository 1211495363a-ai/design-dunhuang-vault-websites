# design-yanyun-hexi-environment-aesthetic-skill

一套从《燕云十六声》河西区域**环境画面与设计语言**中提炼的可复现视觉风格规范。

## 核心边界

本仓库模块只提取：
- 河西地貌
- 边塞与遗迹建筑
- 绿洲与河谷
- 石窟与壁画艺术语言
- 丝路纹样
- 矿物色彩
- 风沙与历史材质

明确排除：
- 人物与角色
- 骑马 / 驼队人物
- 武器与战斗
- 剧情叙事
- 游戏 HUD / UI
- 网游宣传 CG 结构

目标不是“模仿一款网游”，而是将其中河西区域的环境审美提炼为能够用于网页、海报、场景、品牌和视觉系统的独立设计语言。

## 文件

- `SKILL.md`：完整设计规范
- `PROMPTS.md`：可直接复用的生成提示词
- `design-tokens.json`：色彩、比例与关键约束

## 核心公式

`河西地貌 40% + 边塞/遗迹建筑 25% + 石窟与壁画艺术 15% + 丝路纹样 10% + 风沙/历史材质 10%`

## 一句话

> 以河西空间为主体，以历史遗迹和石窟艺术为层次，以丝路纹样为辅助；无人、无剧情、无网游背景。
