# Yanyun Hexi Environment Aesthetic Skill

从《燕云十六声》河西区域中提炼**环境画面与设计语言**的可复现视觉 Skill。

## 核心边界

只提取：

- 河西地貌与空间
- 边塞建筑与遗迹
- 绿洲、河谷与水系
- 石窟与壁面文明痕迹
- 丝路纹样与装饰结构
- 矿物色彩
- 风沙、夯土、岩层、古纸等材质

明确排除：

- 人物与角色
- 骑马者、驼队人物、角色剪影
- 武器、战斗与剧情叙事
- 游戏 HUD / UI
- 任务框、装备卡、技能图标
- 网游宣传 CG 式英雄构图

目标不是模仿一款网游，而是将《燕云十六声》河西区域的**环境美术审美**转译为能够独立用于网页、海报、品牌、展陈、信息图和场景视觉的设计系统。

## 核心公式

> 河西空间骨架 × 边塞遗迹 × 风蚀材质 × 绿洲水系 × 石窟/壁画装饰语言 × 克制的矿物色

## 文件结构

- `SKILL.md`：完整主规范与反偏移规则
- `PROMPTS.md`：简洁可直接复用的提示词
- `design-tokens.json`：色彩、视觉权重、母题与布局 Token
- `references/design-system.md`：细化设计 Token 与验收清单
- `references/prompt-patterns.md`：网页、海报、Skill Board、品牌/展陈等完整调用模板

## 一句话调用

> 使用「燕云十六声·河西环境审美 Skill」：只提取河西区域中的地貌、边塞建筑、绿洲水系、石窟遗迹、色彩、材质与艺术纹样；禁止人物、角色、坐骑、战斗、剧情与网游 UI，以河西环境空间作为绝对主视觉。

## 设计原则

第一眼必须先读到**河西环境**，第二眼才看到纹样和文化细节。

如果第一眼更像敦煌人物壁画、游戏活动页、国潮海报或江南古风，应按 `SKILL.md` 的反偏移规则重新设计。
