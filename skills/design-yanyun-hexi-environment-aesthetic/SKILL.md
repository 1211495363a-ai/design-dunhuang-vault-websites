# 燕云河西 · 环境审美 Skill

## 0. 先确认这套风格是什么

这套 Skill 只提取《燕云十六声》河西区域中可转译为设计语言的**环境、空间、建筑、纹样、色彩、材质和光影**。

它不是：

- 游戏视觉复刻；
- 角色、门派或剧情风格；
- 网游活动页或 CG 宣传图；
- 侠客、坐骑、战斗、装备、任务 UI 的设计系统；
- 只要加飞天、敦煌花纹和黄沙就算完成的“泛敦煌风”。

它要实现的是一种稳定可复现的视觉气质：

> **河西空间为主体，文明遗痕为结构，矿物色为装饰，风沙与时间为材质。**

默认输出中**不得出现人物、角色、坐骑或人物剪影**。若用户明确要求加入人物，再把人物作为次级元素处理，且不得改变本 Skill 的环境主导原则。

## 1. 五个不可替换的视觉锚点

任何使用本 Skill 的作品，至少同时满足其中四项；少于四项时，容易退化为普通“西域/敦煌/国风”。

### A. 河西空间骨架

优先使用横向延展、层层后退、天地尺度显著的空间。

常用结构：

- 戈壁平原 + 远山；
- 风蚀雅丹 + 低矮古城；
- 河谷/浅水系 + 绿洲边缘；
- 崖壁石窟 + 裸露山体；
- 夯土关隘/烽燧 + 大面积天空；
- 古道穿过荒地、城墙、河谷或绿洲。

场景要给人“地貌先存在，建筑后来嵌入”的感觉。不要用宫殿、园林或完整城市天际线占据画面。

### B. 边塞文明遗痕

建筑与物件不追求精致完整，而强调长期风化后的痕迹：

- 夯土城墙、残垣、缺口、坍塌边缘；
- 烽燧、关隘、土堡、驿站；
- 石窟、龛洞、崖壁开凿面；
- 残碑、刻石、旧木构、绳索、旗幡残片；
- 旧路、车辙、石阶、土坡、水渠。

用“遗留痕迹”表达历史，而不是靠人物表演历史。

### C. 河西矿物色系统

主色不使用现代高纯度色，而使用土石与壁画矿物色之间的关系。

基础配比：

- 55–65%：沙金、土黄、赭石、干土褐；
- 20–30%：米白、古纸、岩灰、烟尘灰；
- 8–12%：石绿、青金、灰蓝；
- 3–8%：丹赤、深褐、墨黑作为强调与压重。

色彩必须呈现**干燥、粉化、哑光、受时间侵蚀**的状态。避免纯金、霓虹蓝、赛博紫、电商红、玻璃渐变和高亮金属感。

### D. 石窟/丝路纹样的“结构化使用”

纹样是设计语法，不是主题本身。

可用：

- 云气纹；
- 莲瓣与忍冬；
- 几何边饰；
- 藻井式层级组织；
- 卷草、连续带饰；
- 鹿、鸟、瑞兽等小型纹样片段；
- 飘带式长曲线，但不要转化成人物飞天主体。

纹样只进入三类位置：

1. 边框 / 分区结构；
2. 局部强调；
3. 低对比材质底纹。

禁止满屏铺纹、堆叠花瓣、巨大宗教人物、飞天占据主视觉。

### E. 风沙与时间材质

所有材质要有“被使用、被侵蚀、被风沙覆盖”的时间感。

优先材质：

- 砂砾与风纹；
- 岩石层理；
- 夯土裂纹；
- 壁画粉化、剥落、残彩；
- 旧木干裂；
- 古纸纤维；
- 褪色织物；
- 灰尘、轻雾、干燥水痕。

材质是辅助，不要用重噪点压掉正文和功能信息。

## 2. 构图规则

### 2.1 先场景，后装饰

视觉优先级必须保持：

**空间 > 地貌 > 建筑/遗迹 > 光影 > 材质 > 纹样 > 文本装饰。**

纹样不能替代空间构图，装饰不能抢走地貌的尺度感。

### 2.2 推荐四类构图

#### 横向长卷

适合网站首屏、横幅、展板。

- 地平线拉长；
- 远山、古城、河谷分层后退；
- 一侧可放关隘或石窟形成重量；
- 另一侧保留天空或荒地作为文字区。

#### 遗迹主视觉

适合海报和封面。

- 一处烽燧、土城、石窟或崖体为主视觉；
- 主体占画面约 25–45%；
- 周围必须留有地貌与天空，不做孤立建筑立绘。

#### 模块化视觉规范板

适合 moodboard、品牌规范、设计展示。

- 场景、纹样、色卡、材质四类模块并列；
- 不使用角色卡或人物展示框；
- 纹样与材质样本必须来自同一色彩系统。

#### 美学地图

适合文化视觉、网页导航、项目介绍。

- 用古道、河谷、水系、城塞、石窟、绿洲形成节点关系；
- 可有路线与地理感，但不要出现游戏小地图、任务点、等级、图标化 NPC 或战斗标记。

## 3. 留白与密度

留白是本风格的核心，不是未完成区域。

- 首屏 / 海报至少保留 25–40% 低信息密度区域；
- 天空、荒地、土墙和古纸都可承担留白；
- 高密度纹样区与高密度正文区不得重叠；
- 一个画面只允许 1 个主纹样系统 + 1 个次纹样系统；
- 宁愿减少装饰，也不要牺牲苍茫和尺度感。

## 4. 光影

优先自然、低角度、干燥空气中的光。

推荐：

- 晨昏暖光；
- 被沙尘柔化的侧光；
- 石窟入口的明暗反差；
- 荒原长阴影；
- 绿洲水面的小范围冷色反射。

避免：

- 强烈体积光柱；
- 游戏 Boss 级逆光；
- 角色轮廓光；
- 魔法发光；
- 赛博、霓虹或高饱和影视调色。

## 5. 建筑语言

建筑必须服从河西环境，不做“古建筑大全”。

优先：

- 厚墙、小开口、低矮体量；
- 夯土、石、木混合；
- 建筑随坡地、崖体、水源布置；
- 局部风化、坍塌、修补痕迹；
- 边塞防御性轮廓和石窟开凿感。

减少：

- 江南飞檐水榭；
- 宫廷琉璃瓦；
- 仙侠悬浮建筑；
- 过度华丽、完整、对称的宫殿群。

## 6. 纹样语法

### 一级：结构纹样

用于框架、标题条、页边与分区。

- 几何带饰；
- 藻井式层级；
- 连续云气；
- 简化卷草。

保持线条清楚，密度中低。

### 二级：强调纹样

用于章节开头、卡片角部、按钮附近、小面积插图。

- 莲瓣；
- 忍冬；
- 小型鹿鸟纹；
- 残片式壁画纹样。

### 三级：材质纹样

用于背景，低对比、低饱和、局部消隐。

- 残彩；
- 风化边饰；
- 局部壁画碎片；
- 古纸上的淡纹。

不得把三级纹样提高到主视觉强度。

## 7. 排版与图形界面

本 Skill 不绑定“古风字体”。优先让现代信息设计与古老材质并存。

- 正文使用清楚、克制的中文字体；
- 大标题可使用有书写感或碑刻感的字形，但不要满页书法；
- 标题、正文、装饰三者要有明确层级；
- 线框、标签、按钮可借鉴古籍分栏和壁画边饰，但保持现代可读性；
- 交互控件不能伪装成游戏任务按钮；
- 禁用血条、任务点、技能图标、稀有度框、角色卡边框、等级徽章等游戏 UI 语法。

## 8. 无人物硬约束

除非用户明确解除，下列元素一律不出现：

- 人物；
- 人物剪影；
- 骑马者；
- 驼队中的人；
- NPC；
- 战斗者；
- 巨型佛教人物或飞天人物作为主视觉；
- 角色装备、武器特写；
- 以人物视线引导画面的“英雄镜头”。

需要“行旅”时，用环境痕迹表达：

- 古道；
- 车辙；
- 驿站；
- 路标；
- 绳索；
- 磨损门槛；
- 残旗；
- 水井；
- 货物留下的空间秩序。

## 9. 无网游背景硬约束

不得因为来源是《燕云十六声》就自动生成：

- 游戏宣传页；
- 游戏世界观介绍页；
- “开放世界”“武侠冒险”等文案；
- 游戏 logo、官方 UI、角色名、任务名；
- 玩家、NPC、技能、装备、等级、探索度等概念；
- 类似登录页、选角页、活动页、抽卡页的构图。

把《燕云十六声》视为**视觉研究来源**，不是最终产品背景。

## 10. 反偏移规则

### 偏成泛敦煌

症状：飞天、莲花、宗教壁画占据主画面。

修正：

- 把纹样面积压到 15–25%；
- 增加戈壁、雅丹、关隘、土城、河谷；
- 让空间尺度重新成为第一视觉信息。

### 偏成普通国风

症状：宫殿、祥云、金色、红黑、书法堆叠。

修正：

- 去掉宫廷元素和金属金；
- 增加风蚀、夯土、石窟、荒原；
- 使用粉化矿物色和更大的留白。

### 偏成游戏海报

症状：中心角色、英雄逆光、战斗张力、任务式构图。

修正：

- 删除所有人物；
- 用遗迹或地貌承担中心重心；
- 取消高戏剧光效；
- 改为场景设计、文化视觉或品牌视觉逻辑。

### 偏成旅游宣传

症状：过于明亮、洁净、景点打卡、照片拼贴。

修正：

- 降低饱和度；
- 强化时间痕迹；
- 减少景点式完整建筑；
- 增加环境连续性和空间叙事。

## 11. 适用任务的执行流程

1. 判断任务载体：网页 / 海报 / 品牌 / 插画 / 展板 / 空间导视 / 视觉规范。
2. 从“地貌、遗迹、绿洲/水系、石窟、纹样”中选 2–4 个场景母题。
3. 先确定空间骨架和留白，再选色。
4. 按 60/25/10/5 附近的色彩结构建立主辅关系。
5. 只选 1 个主纹样系统和 1 个次纹样系统。
6. 加入风沙、夯土、岩层或壁画粉化等材质，但不压信息。
7. 检查是否出现人物或游戏语法；默认全部删除。
8. 缩小画面检查：即使看不清纹样细节，仍应能通过空间、色彩和材质判断为河西，而不是普通古风。
9. 灰度检查：移除颜色后，仍要有清晰的荒原尺度、遗迹结构和留白节奏。
10. 最后才补装饰细节，不用纹样掩盖构图问题。

## 12. 交付前检查

必须同时通过：

- [ ] 无人物、无人物剪影、无骑乘角色；
- [ ] 无游戏 UI、任务、角色卡、装备或宣传页语法；
- [ ] 第一眼先看到空间或遗迹，而不是纹样；
- [ ] 至少有一种河西地貌和一种文明遗痕；
- [ ] 色彩以土石/矿物色为主，没有霓虹或现代高纯度配色；
- [ ] 有明确留白，不满屏装饰；
- [ ] 纹样作为结构或点缀，不承担主体；
- [ ] 材质有风化、粉化、干燥和时间感；
- [ ] 不像泛敦煌、不像普通国潮、不像仙侠、不像网游海报；
- [ ] 即使移除所有文字，画面仍保持完整的河西审美语言。

需要更细的色彩、纹样、提示词与纠错模板时，读取 `references/style-spec.md`、`references/prompt-templates.md` 和 `references/quality-checklist.md`。
