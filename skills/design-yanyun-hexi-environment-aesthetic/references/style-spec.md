# Style Specification

## 1. 视觉配比

推荐把一个完整画面的视觉信息分为：

| 类别 | 建议占比 | 作用 |
| --- | ---: | --- |
| 地貌 / 天空 / 水系 | 40–55% | 建立河西尺度 |
| 建筑 / 遗迹 | 20–35% | 建立文明与历史痕迹 |
| 材质 | 10–20% | 建立风沙、粉化、时间感 |
| 纹样 | 8–18% | 结构与装饰，不抢主体 |
| 强调色 | 3–8% | 丹赤、石绿、青金等节奏点 |

这些数值不是像素级硬指标，而是用来防止“纹样过量”和“景观不足”。

## 2. 色彩 Token

| Token | HEX | 用途 |
| --- | --- | --- |
| sand-100 | `#E7D2A8` | 古纸、浅沙、留白 |
| sand-300 | `#CDA66E` | 沙地、浅土墙 |
| ochre-500 | `#A9763E` | 主土黄、岩层 |
| umber-600 | `#73503A` | 旧木、深土、阴影 |
| cinnabar-500 | `#A74E3C` | 丹赤强调、残彩 |
| mineral-green-500 | `#557C70` | 石绿点缀 |
| lapis-600 | `#405A74` | 青金 / 灰蓝点缀 |
| stone-500 | `#847C70` | 岩灰、烟尘 |
| ink-800 | `#2F2B27` | 深色压重、正文 |
| paper-50 | `#F3E8D1` | 纸张 / 浅底 |

推荐使用“偏灰版本”，不要把 HEX 当作必须原样使用的屏幕纯色。最终质感应通过叠加灰尘、纸纤维或矿物颜料颗粒降低数字色的干净感。

## 3. 场景母题组合

### 组合 A：戈壁边塞

- 大面积戈壁；
- 烽燧或土堡；
- 远山；
- 古道；
- 少量几何边饰。

关键词：苍茫、警戒、风蚀、空旷。

### 组合 B：崖壁石窟

- 裸露岩壁；
- 洞窟 / 龛口；
- 壁画残彩；
- 石阶或栈道遗迹；
- 局部莲瓣 / 忍冬纹。

关键词：沉静、时间、粉化、文明层叠。

### 组合 C：绿洲河谷

- 干旱地貌中的水线；
- 胡杨 / 灌木；
- 低矮聚落；
- 土墙与渠道；
- 石绿和灰蓝局部增加。

关键词：稀缺生机、缓慢、边缘性。

### 组合 D：古道与遗迹

- 道路或车辙为视觉引导；
- 远处关隘或残城；
- 残碑 / 木桩 / 旗幡痕迹；
- 不出现行旅人物。

关键词：经过、留下、消失、距离。

## 4. 纹样占比控制

推荐强度：

- 主边饰：10–15%；
- 角部纹样：3–8%；
- 背景残纹：5–12%，透明度/对比度必须低；
- 主视觉中的完整纹样图形：默认 0–1 处。

若纹样一眼比建筑或地貌更抢眼，则降低 30–50% 对比度或直接删减。

## 5. 材质参数化描述

生成或绘制时可重复使用：

- matte mineral pigment;
- powdery mural surface;
- weathered rammed earth;
- wind-eroded stone strata;
- dry dust haze;
- faded textile pigment;
- handmade paper fiber;
- chipped plaster and residual color;
- low-gloss, low-saturation surface.

## 6. 版式原则

### 桌面网页

- 首屏内容区 45–60%；
- 环境主视觉 40–55%；
- 纹样沿边缘生长，不跨越主要正文；
- 主按钮不做 RPG 风格边框；
- section 间可用细几何带饰作为结构线。

### 移动端

- 环境图缩为局部裁切，不为了完整展示遗迹而压缩文字；
- 纹样减少 30–50%；
- 保留一处最关键的河西识别元素即可；
- 不把背景图裁成“人物不存在但像角色卡背景”的竖向框。

### 海报

- 主体遗迹占 25–45%；
- 大面积天空/荒地承担负空间；
- 标题与纹样不同时占据画面中心。

## 7. 视觉判断句

完成作品后问：

> 如果不知道它与《燕云十六声》有关，这个设计是否仍然成立为一种成熟的河西环境美学？

如果答案是否定，说明作品依赖游戏语境，而不是成功提炼了视觉语言。
