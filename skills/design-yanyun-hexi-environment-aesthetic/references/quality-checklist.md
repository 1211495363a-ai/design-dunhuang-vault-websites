# Quality Checklist

## A. 内容约束

- [ ] 没有人物。
- [ ] 没有人物剪影。
- [ ] 没有骑乘者或有人的驼队。
- [ ] 没有角色、门派、装备、武器叙事。
- [ ] 没有游戏 UI、任务、等级、技能或小地图。
- [ ] 没有把《燕云十六声》当作最终产品背景。

## B. 河西识别度

- [ ] 至少存在一种地貌：戈壁 / 雅丹 / 河谷 / 荒丘 / 绿洲边缘。
- [ ] 至少存在一种遗迹：夯土城墙 / 烽燧 / 关隘 / 石窟 / 驿站 / 残碑。
- [ ] 空间尺度明显，人造物服从自然地貌。
- [ ] 画面有风蚀、干燥和历史时间感。

## C. 色彩

- [ ] 土石暖色是主体。
- [ ] 石绿 / 青金只做点缀。
- [ ] 没有霓虹和现代高纯度色。
- [ ] 没有大面积金属金。
- [ ] 色面呈哑光、粉化、古旧状态。

## D. 纹样

- [ ] 只有一个主纹样系统。
- [ ] 纹样不比地貌/遗迹更抢眼。
- [ ] 飞天人物不作为视觉主体。
- [ ] 纹样用于边框、局部强调或残纹。
- [ ] 不满屏重复莲花或祥云。

## E. 构图

- [ ] 25–40% 左右区域保持低信息密度。
- [ ] 第一眼看到的是空间/遗迹，不是装饰。
- [ ] 主视觉不是“角色站中间”。
- [ ] 没有 RPG 宣传页式居中英雄构图。
- [ ] 远近层级和天地尺度成立。

## F. 材质

- [ ] 至少有两种：风沙 / 岩层 / 夯土 / 壁画粉化 / 古纸 / 旧木 / 织物。
- [ ] 材质不会压正文和功能信息。
- [ ] 表面不呈塑料、镜面或玻璃质感。

## G. 最终判断

缩小到缩略图后检查：

1. 能否先读到河西空间，而不是装饰？
2. 移除所有文字后，画面是否仍成立？
3. 不告诉观者来源于游戏时，作品是否仍像成熟的环境审美设计？
4. 如果去掉纹样，河西识别度是否仍然存在？

若 3 或 4 为“否”，返回修改空间、地貌、建筑和材质，不要继续添加纹样。
