# design-yanyun-hexi-environment-aesthetic

一套从《燕云十六声》河西区域**环境画面与设计语言**中提炼出的可复现视觉 Skill。

## 核心边界

本项目只提取：

- 河西地貌与空间；
- 边塞建筑与遗迹；
- 石窟 / 壁画 / 丝路纹样；
- 矿物色与土石色；
- 风沙、夯土、岩层、古纸等材质；
- 光影、构图、留白和编辑设计语言。

默认明确排除：

- 人物和人物剪影；
- 角色、门派、坐骑、武器、战斗；
- 游戏 UI、任务、等级、技能和角色卡；
- 以“网游”为内容背景的宣传构图。

目标不是复刻游戏素材，而是把河西区域的视觉审美转化成可以用于网页、海报、品牌、插画、展陈和视觉规范的设计系统。

## 文件

- `SKILL.md`：核心规则与执行流程。
- `references/style-spec.md`：色彩、构图、纹样和场景的细化规范。
- `references/prompt-templates.md`：可复用生成提示词与纠偏模板。
- `references/quality-checklist.md`：交付前质量检查表。
- `design-tokens.json`：色彩、比例、材质和禁用项的机器可读配置。

## 一句话原则

> 河西空间为主体，文明遗痕为结构，矿物色为装饰，风沙与时间为材质。

## 使用方式

当任务要求沿用这套视觉语言时，先读取 `SKILL.md`，再根据需要读取 `references/` 中的细则。设计时先确定空间与遗迹，最后才加入纹样。
